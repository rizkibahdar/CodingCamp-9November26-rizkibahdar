# Technical Rules

- Use HTML for webpage structure.
- Use CSS for styling.
- Use Vanilla JavaScript for application logic.
- Do not use React, Vue, Angular, or other frontend frameworks.
- Use Browser Local Storage for data persistence.
- Use Chart.js for the pie chart.
- No backend server or database required.
- Ensure compatibility with modern Chrome, Firefox, Edge, and Safari.
- Prioritize simplicity, readability, and maintainability.
- Do not introduce new dependencies without approval.
