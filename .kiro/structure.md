# Project Structure Rules

Follow this folder structure:

expense-budget-visualizer/
├── .kiro/
│   └── steering/
├── css/
│   └── style.css
├── js/
│   └── script.js
├── index.html
└── README.md

Rules:
- Only ONE CSS file inside css/.
- Only ONE JavaScript file inside js/.
- Keep index.html at the project root.
- All CSS must be inside css/style.css.
- All JavaScript must be inside js/script.js.
- Keep code clean and readable.
- Do not create additional files or folders without approval.
- Do not modify unrelated files.
